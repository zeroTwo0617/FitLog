# FitLog 视觉与字体设计系统

## 适用范围

本文档记录小程序页面的视觉基准、字号层级、主题切换和样式维护边界。设计参考为 `design/fitlog-ui-prototype.html` 及其 CSS，目标画布为 375 x 812 px 手机屏幕。

页面使用微信小程序原生 WXML、WXSS 和 JavaScript。尺寸使用 `rpx`，以 750rpx 设计宽度适配不同设备。

## 字体层级

当前版本以可读性为优先，正文和关键操作文字比原始版本适度放大。底部导航保留紧凑尺寸，避免占用内容空间。

| 层级 | 选择器或用途 | 当前尺寸 |
| --- | --- | ---: |
| 页面主标题 | `.h-title` | 58rpx |
| 首页主标题 | `.home-title` | 62rpx |
| 设置页标题 | `.settings-title` | 58rpx |
| 区块标题 | `.section-title`、`.card-title` | 31-32rpx |
| 重点内容 | 动作名、计划名、饮食名称、消息气泡 | 27-35rpx |
| 全局正文 | `page` 基础字号 | 28rpx |
| 按钮和输入 | 主按钮、输入框、标签 | 24-28rpx |
| 辅助信息 | 描述、状态、说明文字 | 20-24rpx |
| 底部导航 | `.tab-label` | 18rpx，保持稳定 |

维护规则：

- 全局通用字号优先写在 `miniprogram/app.wxss`，页面 WXSS 只覆盖有明确层级差异的内容。
- 标题、正文和辅助信息保持清晰的层级，不要为了填充空间统一使用同一个字号。
- 不使用负字间距；长标题优先换行或使用省略号，不允许遮挡相邻内容。
- 放大文字时保持输入框、发送按钮、训练组输入格和底部操作区的稳定高度，避免页面跳动。
- 图标、序号和状态点不随正文无差别放大。
- 颜色使用 `app.wxss` 的语义 token，不在页面中重新定义同名颜色。

## 主题

浅色主题是默认主题，深色主题由“我的 > 应用 > 设置”中的“黑色主题”开关启用。

- 页面根节点使用 `theme-{{theme}}` 类。
- `miniprogram/app.wxss` 定义浅色默认 token，`.theme-dark` 覆盖深色 token。
- `miniprogram/utils/theme.js` 负责读取、保存主题并同步微信顶栏和自定义底部导航。
- `miniprogram/custom-tab-bar/index.wxss` 使用显式的 `.theme-light` / `.theme-dark` 颜色，因为自定义组件存在样式隔离。
- 主题设置保存在本地存储，重新打开小程序时沿用上次选择。
- 新增页面必须同时检查浅色和深色下的文字对比度、卡片背景、输入框和按钮状态。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `miniprogram/app.wxss` | 全局颜色 token、字号基础、标题、按钮、输入和通用状态 |
| `miniprogram/pages/*/*.wxss` | 页面布局和页面特有的文字层级 |
| `miniprogram/pages/settings/` | 主题设置入口和开关交互 |
| `miniprogram/utils/theme.js` | 主题持久化、页面根节点同步、顶栏和 TabBar 同步 |
| `miniprogram/custom-tab-bar/` | 底部导航的结构、图标、选中态和主题颜色 |
| `design/fitlog-ui-prototype.html` | 可视化设计参考，不属于小程序运行时资源 |

## 验收清单

- [ ] 动作库主动作名、英文名、目标肌群和器械信息不互相遮挡。
- [ ] 教练消息气泡、输入框和发送按钮在小屏幕上不溢出。
- [ ] 训练计划和饮食页面的固定底部按钮不遮挡最后一项内容。
- [ ] 浅色/深色切换后页面底色、顶栏、底部导航和图标同步变化。
- [ ] 字体放大后日历格、训练组输入格和统计图表仍保持稳定尺寸。
